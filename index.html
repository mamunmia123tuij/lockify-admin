Setup checklist

Cloudinary accounts

Uploads use the first account that is enabled and not full (lowest order number first). If it fails, the app automatically tries the next one.

OrderLabelCloud namePresetStatusActions

Add account

Cloud name and preset are not secret. Never put your Cloudinary API secret anywhere in this panel.

Telegram bots

Large files and documents go to a Telegram channel through these bots. Add several bots and the app uses the first one that is enabled and not full.

OrderLabelTokenChat / Channel IDStatusActions

Add bot

Security: bot tokens are readable by every logged-in app user (the app needs them to upload). Use a private channel only for storage, keep the bots limited to that channel, and rotate a token with @BotFather if you suspect a leak.

Storage limits

Telegram bots can upload up to 50 MB but can only download up to 20 MB through the normal Bot API, so 20 MB is the safe value for files users must be able to restore.
